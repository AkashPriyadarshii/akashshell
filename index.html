STEP 1: Create Non-Inheritable Pipes bInheritHandle = FALSE
The shell calls CreatePipe(&rd, &wr, &sa, 0) where sa.bInheritHandle = FALSE. Neither end of the pipe can be accidentally inherited by arbitrary background child processes spawned by other threads.

TECHNICAL SPECIFICATION & FAQ

Frequently Asked Questions

Why build a terminal in pure C instead of Rust or Zig? ↓
Writing directly in pure Win32 C allows complete, zero-abstraction interaction with Windows kernel APIs (CreateProcess, CreatePipe, DuplicateHandle) and Direct2D COM interfaces without wrapper runtimes, foreign function interface (FFI) overhead, or bulky standard libraries.
How does akashshell prevent pipe deadlocks when chaining commands? ↓
Standard pipe bugs occur when child processes or the parent retain open write handles, preventing EOF from ever being signaled. akashshell creates all pipes with non-inheritable handles, duplicates only the exact stdin/stdout handle needed for each child, and closes all parent handles immediately before calling WaitForSingleObject.
What are the system requirements for akashshell? ↓
akashshell runs on Windows 10 (Build 19041+) and Windows 11 with full support for DWM Immersive Dark Mode and hardware Direct2D rendering. Requires zero third-party runtimes or Visual C++ Redistributable packages.
