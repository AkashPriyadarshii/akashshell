FAQ

Technical Questions

Why pure C instead of Rust or Zig? ↓
Pure Win32 C gives zero-abstraction access to CreateProcess, CreatePipe, DuplicateHandle, and Direct2D COM interfaces. No FFI overhead, no standard library bloat, no borrow checker fighting Windows handle lifetimes.
How does akashshell prevent pipe deadlocks? ↓
All pipes start with bInheritHandle = FALSE. DuplicateHandle promotes only the exact stdin/stdout end each child needs. The parent closes its copies immediately before calling WaitForSingleObject — EOF signals cleanly, deadlocks are impossible.
What are the system requirements? ↓
Windows 10 Build 19041+ or Windows 11. Direct2D ships with the OS. Zero third-party runtimes, zero Visual C++ Redistributable, zero installer. Just an .exe.
How does syntax highlighting work without a DOM? ↓
A lightweight C lexical scanner runs on every WM_CHAR event. It marks token ranges and calls IDWriteTextLayout_SetDrawingEffect with pre-created ID2D1SolidColorBrush objects. The GPU does the rest. No DOM, no CSS, no JS parser.
